## 🧩 Overview

**CodeNexus** is a powerful developer platform that enables real-time collaboration, AI integrations, and seamless communication within a unified environment.  
It supports multi-user coding, chat, drawing, and terminal interactions — all optimized for productivity and teamwork.

### Why CodeNexus?
This project aims to streamline collaborative development workflows.  

Key features include:
- 🧩 **Connection & Collaboration:** Real-time multi-user editing, chat, and drawing for dynamic teamwork.  
- 🚀 **AI Assistance:** Integrated AI chat for coding help and intelligent suggestions.  
- 🎨 **Rich UI Components:** Responsive, customizable interfaces for an engaging user experience.  
- 🖱️ **File & Terminal Management:** Efficient handling of project files and remote terminal access.  
- ⚙️ **Extensible Architecture:** Modular design supporting scalability and personalized workflows.

## ⚙️ Getting Started

### 🧾 Prerequisites
Make sure you have the following installed:
- **Programming Language:** TypeScript | JavaScript 
- **Package Manager:** npm  
- **Container Runtime:** Docker  

---

### 🧩 Installation

Build CodeNexus from source and install dependencies.

#### 1️⃣ Clone the repository
```bash
git clone https://github.com/S-kiran-k/CodeNexus
```
#### 2️⃣ Navigate to the project directory
```bash
cd CodeNexus
```
#### 3️⃣ Install dependencies
Using Docker:
```bash
docker build -t S-kiran-k/CodeNexus .
```
Using npm:
```bash
npm install
```
🚀 Usage
Run the project using:

Docker:

```bash
docker run -it {image_name}
```
npm:

```bash
npm start
```
